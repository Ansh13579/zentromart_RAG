# Example output

`call_001_input_file/` contains a generated answer to the customer's recorded
question about the return window for electronics. It includes the recognized
transcript, original text reply, Gnani-generated audio, source evidence and a
tool trace.

The source text was recovered from the existing index using the recorded
chunk IDs; those entries are marked in the metadata. The agent's saved answer
was not edited. Other local test recordings and the full live-session working
directories are not included in this repository.

The final submission demo video must be at most two minutes. Large local
recordings are excluded from Git; place the final shortened `demo.mp4` in the
submission ZIP or link an appropriate hosted copy from the project README.
